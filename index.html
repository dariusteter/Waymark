Waymark — European Cycle Tour Planner

Set your start, your finish, and how you like to ride — Waymark lays out a day-by-day European cycling tour with routes, elevation, food stops, sights, and places to sleep.

▸ First time here? Set up your free routing key
Waymark uses OpenRouteService to calculate cycling routes and elevation. It's free, takes about two minutes, and there's no credit card.
  1. Go to openrouteservice.org/dev/#/signup and create a free account.
  2. In your dashboard, click Create a token → choose the Standard token.
  3. Copy the key it gives you and paste it below.
Your key stays in this browser tab only — it's never sent anywhere except OpenRouteService, and it's not saved when you close the page. If you plan a lot of trips, keep it in a note and paste it in each time.

▸ Optional: add Google for richer places data (paid, ~$0.03–0.04/place)
Adding a Google Places key gets you better coverage and real phone numbers for lodging, food, and attractions. It's not free like the rest of Waymark — Google requires a billing account — but at typical trip-planning volumes it's pennies per trip.
  1. Go to console.cloud.google.com, create a project, and enable billing (a card is required, but Google won't charge anything until you exceed the small free monthly allowance).
  2. In "APIs & Services," enable the Places API (New).
  3. Create an API key under "Credentials." For safety, restrict it to the Places API.
  4. Paste it below.
Leave this blank to use only the free OpenStreetMap data (as before) — Google is tried first when a key is present, and Waymark automatically falls back to OpenStreetMap for anything Google doesn't find, so adding a key can only get you more results, never fewer.
